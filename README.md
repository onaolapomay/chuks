                    #Chuks Kitchen - Food Delivery Web App
​Chuks Kitchen is a high-performance, responsive food delivery application built with React and Tailwind CSS. This project was designed to demonstrate complex UI layouts, state-driven data rendering, and responsive design patterns.
​

-React

-React Router Dom
-Deployment: Netlify

            ​ Application (5 Screens)
​1. Home Screen (Home.jsx)
​Features a hero section with high-quality brand imagery.
​Introduction to the brand's unique value prooposition.
​2. Authentication: Login (Login.jsx)
​Split-screen layout with form validation.
​Support for email/password and social OAuth UI.
​3. Authentication: Sign Up (SignUp.jsx)
​Extended form capture including phone numbers and terms of service.
​Consistent branding across the auth flow.
​4. Explore Menu (Explore.jsx)
​Dynamic Grid: Renders a large fooditems array using .map().
​Category Sidebar: Features a vertical navigation bar for food categories (Popular, Jollof, etc.).
​UX Features: I used a "Back to Top" smooth-scroll button for long lists.
​5. Shopping Cart (Cart.jsx)
​Responsive Layout:This Uses a two-column desktop layout (lg:flex-row) that stacks on mobile.
​Order Summary: A sticky sidebar that calculates Subtotal, Delivery Fees, and Grand Total dynamically using JavaScript's .reduce().
​Quantity Management: Mock logic for increasing/decreasing item counts.


                SETUP
​Install dependencies: npm install
​Run in development: npm run dev
​Build for production: npm run build
